## To publish this folder as a GitHub repository
1. In GitHub Desktop: File > Add local repository > choose this folder > "create a repository" > Publish repository (public).
2. Settings > Pages > deploy from the main branch, root: the tool is then at `https://<user>.github.io/<repo>/`.
Videos are 10 to 40 MB each, under GitHub's 100 MB file limit.
